# Repository Map

Корневой `network-fundamentals-skill` использует следующую модель:

- `SKILL.md` — главный entrypoint для Codex;
- `README.md` — обзор проекта, quick start и карта разделов;
- `references/sources.md` — канонический список RFC и supporting sources;
- тематические каталоги содержат основную базу знаний по конкретной сетевой теме.

Тематические разделы:

- `osi-model`
- `tcp-ip`
- `tcp-vs-udp`
- `dns`
- `ports`
- `nat`
- `cgnat`
- `mtu`
- `gateway`
- `routing`
- `ipv4`
- `ipv6`
